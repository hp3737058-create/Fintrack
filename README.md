💚 FinTrack — Personal Finance Landing Page

📁 About

FinTrack is a modern personal finance landing page designed in Figma. It helps users track expenses, manage budgets, monitor spending, and work toward their financial goals through a clean and user-friendly design.

🎨 Design Tool

- Tool: Figma
- Project Type: Landing Page UI/UX Design
- Category: Personal Finance / FinTech
- Design Style: Modern, clean, minimal, and user-friendly

✨ Design Features

- Navigation Bar: FinTrack branding, navigation links, and a Get Started button.
- Hero Section: A clear headline introducing the product, supporting text, and a Get Started call-to-action button.
- Monthly Overview Dashboard: Displays total balance, income, expenses, and monthly spending progress.
- Top Categories: Shows spending categories such as Food & Dining, Transport, and Shopping & Bills.
- Features Section: Highlights expense tracking, budget planning, financial insights, and access across devices.
- Footer: Can include brand information, navigation links, and copyright details.

🧩 Design Components

- Reusable feature cards for consistent presentation.
- Consistent colors, typography, spacing, and rounded corners.
- Auto Layout used to organize and align interface elements.
- A consistent green and light-mint color palette.
- Responsive layout considerations for different screen sizes.

🎯 Target Audience

FinTrack is designed for students, working professionals, and individuals who want to manage their personal finances and develop better spending and saving habits.

🎨 Design Choices

- Green: Represents growth, money, and financial confidence.
- Light Mint Backgrounds: Create a calm, welcoming interface.
- White Cards: Improve readability and organize financial information.
- Simple Typography: Makes important information easy to scan.
- Clear Call-to-Action Buttons: Help users identify the next step.
